# 工作思路总览 · 这套工作台怎么转起来

> 给第一次接触本工作台的人（含管理者）：5 分钟看懂整体怎么干活、人和 AI 各干什么、为什么越用越好。安装命令见 `README.md`，设计论证见 `为什么这样设计_v1.md`——本文只讲**怎么转**。

## 一、一分钟看懂：一份报告的旅程

```
中文报告 docx 进来
   │
   ├─ 阶段 0-9  事实层（既有流程不变）
   │   体检 → 建术语表 → 逐节翻译 → 机器全量检查
   │   （结构/数字/术语/回译对账，15 个既有脚本，机器兜底，人基本不看）
   │
   ├─ 阶段 9.5  表达层验证三关（本工作台新增）
   │   ① 校准关：AI 评审先考锚点试券 → 持证上岗（一次性）
   │   ② 评审关：持证评审按定版 rubric 逐段四维打分，低分必须引原文
   │   ③ 抽检关：分层抽 10%，critical 一票否决 → 判定报告（带全套 hash）
   │
   ├─ 阶段 10  沉淀：人裁决 3-8 条拿不准的 → 回填术语/风格资产
   │
   └─ 阶段 11  签发：人核 critical/major 明细 → 签字 → 交付声明
              （阶段 12：攒几份报告做一次回顾，框架自己升级）
```

人工时账：首建锚点约 1.5 小时（一次性）；此后每份 5 万字报告 **人的全部投入 ≤30 分钟**。

## 二、三层分工：谁干什么

| 层 | 干什么 | 判据（一句话） |
|---|---|---|
| 🧠 **模型（语义层）** | 翻译、润色、rubric 打分、拿不准项的初筛 | 每次输入都不一样的活 |
| ⚙️ **工具（执行层）** | 结构检查、数字对账、抽样、阈值判定、台账、hash 留档 | 同输入必同输出的活——**判定权只在这层** |
| 📦 **资产（知识层）** | 术语表、锚点集、rubric、缺陷台账、风格记忆 | 要跨报告活下来的东西——**越用越厚** |

关键约定：**模型可以打分，但不能裁决**。所有「过/不过」的判定都由确定性代码执行（阈值写死在工具常量里，hash 留档）——AI 参与、机器裁决、人拍板方向。

## 三、人和 AI 的分工契约

**人只出现在 7 个拍板点**（详见 README 表）：签认 rubric、标锚点、裁决不确定项、抽核评审理由、签发签字、确认资产回填、确认框架修订。每个拍板点都是结构化选择（「A 还是 B，请选」），不是开放式问题——人做选择题，不做问答题。

**AI 干全部执行**，但有三条硬约束：
1. **三会话分离**：翻译、评审、校准是三个独立会话——评审必须持校准证书，防止自己审自己
2. **门禁 fail-closed**：输入不完整、证书无效、rubric 改动未重校准——一律拒出分，宁可误拦不可放行
3. **留痕**：每个 PASS 可回溯到「哪个 rubric 版本（hash）、哪个评审者（持证）、哪份文件（sha256）、哪次抽样（seed）」

## 四、越用越好的机制（这套东西的核心卖点）

每份报告的产出不只是英文稿，还有三样「复利资产」：

1. **裁决沉淀**：你每次拍板「X 用 A 不用 B」，自动回填术语表（provisional）；同类裁决出现第二次自动升格为正式——**第二份报告开始，上一份的判断直接生效**
2. **错误回流**：抽检发现的错误模式（某类术语反复出问题、某类翻译腔反复出现）→ 回流为术语表补条目/风格规则/评审 rubric 修订提案（人确认后生效）
3. **缺陷台账**：每稿的 critical/major 密度入库，「基本无错」从口说变成**统计趋势**——台账连续全绿，签发信心有据

框架自身也在这个回路里：攒 3-5 份报告做一次回顾（`l10n-improve`），错误模式提炼成修订提案，人确认后版本化升级；使用侧还可导出脱敏反馈包发回维护者远程迭代。

## 五、三种典型场景的入口

| 你遇到的事 | 说一句话 | 框架自动走 |
|---|---|---|
| 新报告要翻 | 「翻译这份报告」 | 总纲全流程：0.5 建术语表 → 0-9 翻译+机器检查 → 9.5 表达层三关 → 沉淀 → 签发 |
| 翻好了要交付 | 「交付前抽检」 | 校准有效性检查 → 抽样 → 判定 → 签发卡（人核完签字） |
| 客户改稿了 | 「客户改了这两节」 | 增量路径：只重译改动段（人工裁决过的段落不重跑）→ 改动段必过评审 → 新版签发 |

## 六、和现有流程的关系（一句话）

**叠加，不替换**：事实层的 15 个脚本和全部译文库原样保留；本工作台加的是表达层验证链和全流程的人机协作设计。任何时候想退回旧方式，跳过 9.5-11 即可。
